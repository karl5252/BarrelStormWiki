## BarrelStorm

**BarrelStorm** is a fast, top-down arcade tank combat game set in an effectively endless, chunk-generated wasteland. The Motherplant deploys armored vehicles from below the frozen earth to destroy hostile war machines and recover precious **CORES**.

The *battlefield* is stripped down, legible, and explosive. The *world surrounding it* is steeped in neo-Soviet industrial pageantry, civic mythology, and an increasingly unreliable bureaucracy.
