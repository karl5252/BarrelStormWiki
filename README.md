# BARRELSTORM

> **THE MOTHERPLANT NEEDS YOU.**
>
> **FOR THE MOTHERPLANT!**

BarrelStorm is a fast, top-down arcade tank combat game set in an effectively endless, chunk-generated wasteland. The Motherplant deploys armored vehicles from underground infrastructure to fight hostile war machines and recover precious **CORES**.

Its world is dressed in absurd, quasi-religious, neo-Soviet industrial propaganda. Its combat, however, is stripped-down and immediate: sharp silhouettes, heavy impacts, drifting tracks, and the overwhelming spectacle of machines emerging from below.

## Direction update (October 2026)

The earlier **assault-on-cities / civilians** direction is retired. The current concept follows an armored scavenging expedition across hostile wasteland. Propaganda posters and the Motherplant mythology remain.

This wiki separates **confirmed design decisions** from **proposals** and **open questions**. It should not be mistaken for a finished implementation specification.
